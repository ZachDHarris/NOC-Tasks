# NOC Handoff Widget

A small embeddable HTML widget showing the daily NOC shift handoff (Day / Evening / Night) with per-task ownership for Alerts, Chats, and Emails & Tickets. Includes day navigation and auto-highlights today.

See [handoff-mini-713x419.html](handoff-mini-713x419.html) for the widget source — a self-contained `713x419` HTML/CSS/JS block meant to be dropped into a dashboard or iframe.
